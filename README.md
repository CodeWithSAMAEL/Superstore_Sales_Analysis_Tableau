# Superstore Sales Analysis in Tableau

Interactive Tableau dashboard analyzing sales performance, profitability, product trends, and regional contributions using Superstore sales data.

## Overview of the Project

In this project, the sales data of Superstore is used for analyzing business performance based on region, category, and products.

The dashboard will provide information about revenue generation, profitability, sales trends, and product efficiency.

## Dataset Information

- Records: 2,000
- Fields: 10
- Metrics:
  - Revenue
  - Profit
  - Units Sold
  - Category
  - Product
  - Region
  - Salesperson

  ## Tools Used

- Tableau
